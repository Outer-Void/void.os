# AXIOM Launcher

System-focused Android launcher built by Outer-Void.

## Philosophy

Stripped to function.  
Built for clarity.  
Made for control.  
Nothing extra.  
Everything intentional.

## Features

- Custom home launcher
- App grid
- Search system
- Settings system
- Font customization
- Icon pack selection
- System-aware UI
- VOID.SYS integration ready
- VOID.SYS intended icon pack integration

## Status

A5 — Settings foundation added on top of the A1 core launcher

## Roadmap

- A2 System Panel
- A4 VOID.SYS icon mapping and integration
- A5 Settings polish and expanded controls
- Third-party icon pack parsing

./gradlew assembleDebug
