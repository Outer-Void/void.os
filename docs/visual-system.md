# AXIOM Visual System

AXIOM A3 defines the launcher as a matte black system surface aligned with VOID.SYS. The interface should feel technical, restrained, and purpose-built.

## Palette

- Background: `#0B0B0B`
- BackgroundAlt: `#111111`
- Surface: `#161616`
- SurfaceAlt: `#1A1A1A`
- IconBackground: `#0F0F0F`
- Border: `#1E1E1E`
- BorderAlt: `#2A2A2A`
- BorderDim: `#141414`
- TextPrimary: `#D8D8D8`
- TextSecondary: `#777777`
- TextDim: `#444444`
- TextInactive: `#333333`
- Amber: `#FFD000`
- AmberDim: `#996000`
- Danger: `#E53935`
- BrandBlue: `#2196F3`

## Typography

Use monospace/system typography by default. Clock, labels, search, settings rows, and system indicators must share the selected AXIOM font path and fall back safely to monospace when unavailable.

## Dock Rules

The dock is a rounded matte control strip near the bottom of the launcher. It uses three Canvas-only controls: settings/power dial, app grid, and system ring. No text labels appear in the dock. A small amber focal dot marks the center control.

## Icon Cell Rules

Apps render inside rounded square cells using `IconBackground` and `Border`. Icons remain centered around 70% scale by default. Labels sit below the tile in muted monospace and may be hidden by settings.

## Accent Discipline

Amber is reserved for active system signals: header rules, corner highlights, dock indicators, search cursor, and pulse dots. Red is limited to destructive actions. Blue is reserved for future brand/system exceptions.

## Mockup Alignment Notes

A3 screens use sparse matte fields, thin corner brackets, short amber underlines, muted app labels, and subtle layered depth. Ambient keeps the dock absent and focuses on the ghost `A`, vertical line, lower-left date, and `SYSTEM ONLINE.` status.

## A2 System Panel

The A2 panel follows the same AXIOM visual language: matte black background, controlled amber accent, corner brackets, 4-column rounded action tiles, and DockBar continuity with Home, Search, and Settings.
